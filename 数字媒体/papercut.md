# 纸上生花——融合对称生成与镂空结构提示的剪纸互动工坊


## 内容
| 环节   | 建议内容                                                        | 作用        |
| ---- | ----------------------------------------------------------- | --------- |
| 文化导入 | 首先，设置“节庆窗花”“祝福赠礼”等少量任务(用节庆、生活场景或简短故事)，引出本关作品的用途和寓意          | 让用户知道为什么剪 |
| 纹样解读 | 精选6—8个有出处的元素，说明来源、寓意和适用语境                                   | 文化内容可信、具体 |
| 分步教学 | 选纸、折叠、描样、裁剪、展开，每一步提供简短提示                                    | 让用户知道怎么剪  |
| 折剪交互 | 在折叠区域绘制或放置剪切形状，实时生成对称结果                                     | 成为核心操作    |
| 关卡挑战 | 从跟随辅助线，到自行判断局部剪法，逐渐减少提示                                     | 建立难度递进    |
| 结构提示 | 标出可能脱落的独立区域，提示过细连接处                                         | 体现技术深度    |
| 成果展示 | 操作完成后逐步展开，展示局部剪刻如何形成整体图案，增加作品收藏、文化知识卡片，导出剪纸图及创作卡，提供一种窗花场景预览 | 增强完成感     |
| 自由创作 | 自选折叠方式、绘制剪裁路径、预览展开效果、保存作品                                   | 鼓励自主表达    |





1. 首页：“纸间光影”——2.5D 视差滚动叙事剧场（重美学与故事感）
	* **核心创意**：将剪纸与“窗格透光”“皮影戏台”结合，把整个网页做成一个层叠的立体纸雕剧场。
	* **交互体验**：用户向下滚动页面时（Scrollytelling），前景的窗棂、中景的民俗人物剪纸、背景的宣纸山水以不同速度产生视差位移；鼠标移动充当“烛光/晨光”光源，实时改变剪纸层投射在背景上的柔和阴影，讲述一段民俗故事（如胶东渔家祈福、二十四节气或高密神话）。
2. 传统模块：
   介绍各地剪纸
	   1. 沂蒙剪纸（琅琊剪纸）：窗花，月牙纹等
	   2. 高密剪纸：金石味等
	   3. 胶东海阳/烟台剪纸：渔家民俗窗花
3. 现代化模块：革命老区，动画（葫芦娃、中国奇谭小满）
4. 剪纸创作模块：添加非对称不对折的剪纸创作，阳刻、阴刻。
5. 成果展示模块：支持一键贴到虚拟古建窗户或生成现代文创周边（帆布袋、手机壳、节气海报）预览。
   
纸张设计与色调：宣纸暖白（`#F6F2E9`）、朱砂红（`#B8251E`）、黛蓝（`#233342`）与泥金（`#D4AF37`），在全局叠加一层 4% 透明度的宣纸纤维噪点贴图，并为剪纸 SVG 元素添加多层 `filter: drop-shadow()`，营造纸张悬空浮起的立体浮雕感。

剪刀光标：将鼠标指针替换为“微距光点”或“刻刀/剪刀”光效，移动时留下极细的金色或红色镂空轨迹；利用 SVG 的 `stroke-dasharray` 与 `stroke-dashoffset` 属性，让页面上的剪纸图案在滚动进入视口时像被无形刻刀实时刻画出来一样生长呈现。

模式切换：把常见的深浅色模式（Dark/Light Mode）改造为剪纸专属的“阳刻（红线留底，喜庆热烈）”与“阴刻（墨底镂空透光，神秘深邃）”一键切换，既贴合剪纸专业本体，又极具视觉反差感。

感官交互：网页角落加入音效开关，背景配以轻柔的空灵民乐，按钮悬停与切换时触发真实的“纸张摩挲声”与“剪刀咔嚓声”。点击“展开”时配合清脆的纸张翻折音效
