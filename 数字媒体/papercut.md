# 纸上生花——融合对称生成与镂空结构提示的剪纸互动工坊

## 定位
面向剪纸初学者，以传统纹样及其文化寓意为内容，通过折剪交互、对称展开和镂空结构提示，帮助用户理解剪纸工艺并完成自己的创作。

## 实现方式
桌面软件

不使用换图关卡，同时设计两条递进线：

- **技法线**：简单对折 → 多次折叠 → 更复杂的镂空与连接结构。
- **文化线**：认识单个纹样 → 理解使用场景 → 根据寓意组合设计。
例如，入门关侧重认识对称与剪裁；中间关让用户为某个节庆场景选择、完成合适的纹样；最后一关给出“为家人设计一幅表达祝福的剪纸”这样的开放任务，让用户解释自己的设计寓意。

- 入门：理解折叠与对称，完成简单作品。
- 纹样：认识一个有明确来源的传统纹样及其寓意。
- 工艺：学习镂空和连接关系，理解为什么有些地方不能剪断。
- 场景：为某个具体民俗场景完成适合的作品。
- 综合：根据表达意图选择、组合已经学过的元素。自由创作完成后，可以保存作品、导出可打印剪纸模板
## 细节

将 **“对称生成＋展开动画”作为基础核心，“镂空后的连通区域分析”作为技术亮点**。

例如，用户切断某处连接后，系统高亮可能脱落的区域，并显示修改前后的结果。这样的反馈与剪纸过程直接相关，比另外接入一个聊天助手更能说明技术的作用。

## 要点
- **文化理解与资料依据**：选定一个有可靠资料支撑的剪纸传统或主题系列，标注图样及文化介绍的来源。
- **数字表达创新与交互体验**：重点打磨折叠、裁剪、展开和自由创作，避免操作只剩下机械描线。
- **艺术表现质量**：统一纸张质感、图样、界面和动画风格。
- **传播与传承价值**：明确面向谁使用，例如剪纸初学者或校园文化体验活动，并用实际试用验证用户是否学会了基本方法。

### 二、 三个高创意网页设计方案（可单选或融合）

想要摆脱同质化，建议将网页定义为“可体验的数字艺术品”，以下三个方向兼顾了创意高度与8天内的前端可行性：

* **方案 A：“纸间光影”——2.5D 视差滚动叙事剧场（重美学与故事感）**
* **核心创意**：将剪纸与“窗格透光”“皮影戏台”结合，把整个网页做成一个层叠的立体纸雕剧场。
* **交互体验**：用户向下滚动页面时（Scrollytelling），前景的窗棂、中景的民俗人物剪纸、背景的宣纸山水以不同速度产生视差位移；鼠标移动充当“烛光/晨光”光源，实时改变剪纸层投射在背景上的柔和阴影，讲述一段民俗故事（如胶东渔家祈福、二十四节气或高密神话）。


* **方案 B：“一刀万象”——虚拟折纸与实时镂空工坊（重交互与参与感）**
* **核心创意**：还原剪纸“折、剪、展”最具仪式感的瞬间，让用户在网页上亲手剪出窗花。
* **交互体验**：通过 HTML5 Canvas / SVG 实现“虚拟红纸对折”（四折、六折、八折）；用户用鼠标或触控板在折纸一角自由绘制或盖印传统纹样（月牙纹、锯齿纹、铜钱纹），点击“展开”时配合清脆的纸张翻折音效，自动镜像生成完整对称的精美窗花，并支持一键贴到虚拟古建窗户或生成现代文创周边（帆布袋、手机壳、节气海报）预览。


* **方案 C：“刀锋谱系”——剪纸视觉基因拆解与数据可视化（重信息设计与解构美）**
* **核心创意**：把非遗剪纸拆解为一套严谨而浪漫的“视觉语法”，用动态图表与微距视图呈现。
* **交互体验**：首屏将一幅复杂的经典剪纸进行 **3D 爆炸图式分层拆解**（外轮廓层、核心人物层、装饰花草层、阴刻/阳刻细节层）；内页通过交互式径向图、色彩光谱图对比南北剪纸流派、刀法符号（如“千刀不断、万眼不乱”）与吉祥寓意，点击任意纹样即可触发 SVG 路径生长动画，动态演示一刀一剪的运刀顺序。



### 三、 让网页“美观又有高级感”的视觉与微交互细节

评委在看网页作品时，前 15 秒的视听质感决定了印象分。建议加入以下细节：

* **打造真实的纸张肌理与光影层次**：放弃纯白底（`#FFFFFF`）配纯红（`#FF0000`）的刺眼搭配，采用宣纸暖白（`#F6F2E9`）、朱砂红（`#B8251E`）、黛蓝（`#233342`）与泥金（`#D4AF37`）构成的新中式配色；在全局叠加一层 4% 透明度的宣纸纤维噪点贴图，并为剪纸 SVG 元素添加多层 `filter: drop-shadow()`，营造纸张悬空浮起的立体浮雕感。
* **定制刀剪微交互与生长动效**：将鼠标指针替换为“微距光点”或“刻刀/剪刀”光效，移动时留下极细的金色或红色镂空轨迹；利用 SVG 的 `stroke-dasharray` 与 `stroke-dashoffset` 属性，让页面上的剪纸图案在滚动进入视口时像被无形刻刀实时刻画出来一样生长呈现。
* **融入“阳刻/阴刻”双模式切换**：把常见的深浅色模式（Dark/Light Mode）改造为剪纸专属的“阳刻（红线留底，喜庆热烈）”与“阴刻（墨底镂空透光，神秘深邃）”一键切换，既贴合剪纸专业本体，又极具视觉反差感。
* **搭配沉浸式 ASMR 听觉反馈**：《评分标准》明确考察“视觉、听觉、交互整体性”，建议在网页角落加入音效开关，背景配以轻柔的空灵民乐，按钮悬停与切换时触发真实的“纸张摩挲声”与“剪刀咔嚓声”。
