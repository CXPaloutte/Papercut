# 剪映古今——山东剪纸文化互动体验与创作

> 新版规划：以山东剪纸为文化主线，将现代化融入讲解、再设计、数字创作和生活应用。本文描述目标方案；具体实现状态见第八节。旧规划保留用于对照。

## 一、作品定位

### 1. 核心定位

面向青少年、大学生及剪纸初学者，以山东剪纸的具体作品和生活场景为切入点，通过互动赏析、纹样转化与数字创作，让用户完成一件具有个人表达的剪纸作品。

核心问题：用户如何从“看见一幅传统剪纸”，走到“理解一种表现方法”，再到“用它表达今天的生活”？

### 2. 主题表达

- 文化来源：精选有出处的山东剪纸案例。
- 学习内容：纹样、构图、对称、留纸与镂空、纸面连接。
- 当代表达：将所学方法用于个人祝愿、校园生活和家乡印象。
- 最终成果：剪纸图案、生活场景预览和记录来源与创作意图的创作卡。

“古今”的联系通过具体设计过程体现：传统案例 → 方法提取 → 当代设计 → 用户作品。

### 3. 形式与规模

采用网页交互作品，以桌面端创作为主，兼顾移动端浏览和基础操作。首页加四个主要模块：纸间寻根、纹样新生、指尖剪艺、一纸入生活。

首个可演示版本完成一个有出处的文化案例、一条从传统到当代的创作任务、三段入门练习和两种成果场景。后续再扩展地域案例及自由构图能力。

## 二、体验主线

### 1. 主任务：“剪一份今天的祝福”

用户从经过核实的节庆或祝福主题案例出发，观察其中的构图与装饰方法，完成一幅属于自己的窗花，再将它制作成现代祝福海报。

此任务可复用现有对称创作功能，适合作为首版完整体验。海报文字位于独立排版层，不作为纸面裁剪的一部分。

体验顺序：

1. 首页提出任务，展示传统窗花与现代海报中同一幅图案。
2. 查看一件传统案例，认识来源、使用场景和一种具体表现方法。
3. 查看设计演示，理解保留了哪些方法、改变了哪些内容。
4. 完成对称、连接和自主变化三段练习。
5. 为作品命名，在窗格和海报中预览。
6. 导出剪纸图或创作卡，收藏后可继续修改。

用户也可直接进入工坊；练习不设强制解锁。首次体验目标时长暂定 5—8 分钟，需通过真实试用调整。

### 2. 扩展任务：“把家乡剪进今天”

用户选择经过核实的地域案例，提取其中一种构图或装饰方法，再加入校园、家乡建筑或当代生活元素，完成家乡印象作品。

人物、建筑及场景叙事可能需要非对称构图，因此此任务在平面自由剪模式完成后上线。具体题材由可获得的文化资料和原创设计素材决定，不将普通几何图案直接标记为某地传统纹样。

## 三、页面与模块设计

### 1. 首页：一纸连接古今

**目标：** 让用户快速理解主题，并开始体验。

页面内容：

- 主标题“剪映古今”，副标题“从山东剪纸出发，剪出今天的生活”。
- 首屏采用窗格、剪纸、纸面背景三层构图。
- 简短演示同一图案从窗花进入现代海报的过程，直接呈现作品主题。
- 两个入口：“循纹样寻根”“开始我的第一剪”。
- 下方展示四个模块入口与一项精选任务。

交互以轻量层次位移和图案展开为主。首页演出可跳过，移动端使用简化过渡。复杂鼠标光源和连续滚动剧场列为后期增强，不阻挡进入工坊。

### 2. 纸间寻根：从具体作品理解地域文化

**目标：** 让用户说得清“看的是哪件作品、与什么生活场景有关、值得观察什么”。

资料采集候选包括沂蒙地区、高密、胶东地区的剪纸案例。正式栏目名称应依据核实后的资料确定；不预设“沂蒙剪纸”和“琅琊剪纸”为同义名称，也不将胶东不同地区的案例混作一个统一流派。

每张案例卡统一包含：

| 信息 | 内容要求 |
| --- | --- |
| 作品与来源 | 作品名称、地域、作者或收藏来源；未知项不猜测 |
| 生活场景 | 何时、何处、为何使用，有资料支持才作具体解释 |
| 纹样解读 | 只提炼少量可解释的元素，寓意须对应具体语境 |
| 形式观察 | 标出对称关系、局部装饰、留纸和镂空等可见特征 |
| 资料标注 | 来源链接、素材使用情况，区分原作与团队再设计 |
| 后续入口 | “看看它如何变成新设计”，进入对应转化案例 |

交互采用“看全图—点局部—读短解释”。先完成一个资料完整的案例，扩展版再形成三组案例和约 6—8 张元素卡。未核实的材料留在内部资料表，不作为成品内容展示。

### 3. 纹样新生：展示传统方法怎样用于今天

**目标：** 让用户理解再设计过程，为动手创作提供方法。

每个案例使用固定的四步结构：

1. **看来源：** 回看原作，知道设计依据。
2. **找方法：** 用高亮标出一项可学习的表现方法。
3. **做变化：** 分步展示元素简化、位置调整、重复组合或主题替换。
4. **试创作：** 将对应原创练习模板载入工坊。

首版只完成“剪一份今天的祝福”转化案例，提供传统参考、团队再设计和空白练习三个可区分的视图。重点回答“沿用了什么、改变了什么、为什么这样改”。

再设计作品标注为团队原创练习，并关联参考资料。传统作品若包含复杂人物和非对称结构，仅提取适合本次练习的方法，不强行将整件作品转成对称团花。

后续主题：

- 校园祝愿：用于毕业、入学等个人表达。
- 家乡印象：结合生活观察形成原创构图。
- 家乡记忆：具备可靠材料时，加入山东地域故事或红色记忆专题。

航天、冬奥暂不列入核心范围。动画用于解释构图变化、呈现简短故事；不单独建设影视案例展区。

### 4. 指尖剪艺：从入门练习到自主创作

**目标：** 用户能理解操作结果，并完成作品。

桌面布局：左侧工具，中间纸面，右侧展开预览与连接提示；顶部保留任务名称与参考案例入口。移动端将工具分组收纳，预览可切换，避免多个窄栏同时出现。

#### 入门练习

| 练习 | 用户操作 | 学习目标 | 反馈方式 |
| --- | --- | --- | --- |
| 一剪成花 | 在辅助区域剪出一个孔，再更改位置或大小 | 观察局部剪口如何形成对称图案 | 同时高亮原始剪口与重复位置 |
| 留住连接 | 在专门设计的练习图中观察断开，再撤销或改用较小剪口 | 理解保留纸面的连接关系 | 标出分离区域，解释哪次操作造成变化 |
| 剪出心意 | 选择练习模板，至少完成一次自主调整并命名 | 用已有方法表达自己的意图 | 展开作品，邀请用户填写简短创作说明 |

练习完成条件以操作和理解为主，不对审美进行自动评分。自由创作中不将所有分离区域判为错误，用户可能有意裁去它们。

#### 创作模式

- **对称折剪：** 首版主模式。沿用四瓣、六瓣、八瓣对称、预设剪口、逐点闭合裁剪、纸色、折线辅助、撤销重做。
- **平面自由剪：** 第二阶段实现。不对折、不自动重复剪口；先完成基本裁剪、撤销、预览、保存与导出的一致性，再用于人物、建筑等题材。
- **阴刻与阳刻教学：** 先制作同一图案的静态或分步对照，明确留纸与镂空区域。完整创作模式另行实现，不能以换色或图像反色代替技法切换。

连接反馈采用“高亮位置＋短原因＋下一步建议”。现有检测只估算与最大主体分离的明显区域，不作为纸张强度或实体可剪制性的保证。过细连接分析在输出尺寸和判断方法明确后再加入。

### 5. 一纸入生活：让作品有一个明确去处

**目标：** 形成完成感，并把用户创作与当代生活联系起来。

首版包含两种场景：

1. **窗格透光：** 复用现有窗花场景，表现剪纸的镂空效果。
2. **祝福海报：** 使用同一幅剪纸，允许填写标题、赠语和署名，提供两种简洁排版。

后续加入帆布袋、手机壳等样机，但始终使用用户的真实作品作为画面内容。

输出区分：

- 剪纸图：透明背景 PNG、矢量 SVG，沿用现有导出。
- 场景图：包含窗格或海报背景的图片，需要新增合成导出。
- 创作卡：作品名、作者署名、文化参考、所用方法和个人说明，需要新增排版导出。

收藏保持可再次编辑，新增任务来源与创作说明等信息。首版仍保存在当前浏览器，不宣传跨设备同步。文创预览用于展示视觉应用，不承诺实体生产效果。

## 四、内容如何贯穿四个模块

每个案例关联一条连续路线：文化来源、转化演示、练习模板、用户作品和成果卡。

例如，用户从某张案例卡进入工坊后，工坊仍能查看来源与本次学习的方法，导出的创作卡也能记录参考。直接进入自由创作的用户可选择不关联案例，避免自动给原创作品添加不真实的地域归属。

模板切换、折法变更和任务切换可能替换当前作品，需要提供保留草稿或确认入口。新增素材和模板使用统一尺寸与中心定位，确保画布、预览和导出结果一致。

## 五、视觉与声音设计

- 主色：宣纸暖白 `#F6F2E9`、朱砂红 `#B8251E`、黛蓝 `#233342`；泥金 `#D4AF37` 用于少量点缀。
- 页面以纸张肌理、边缘阴影和留白形成层次；正文区域减少纹理干扰。
- 首页与成果页可有较丰富的光影，创作区保持清晰的边界、选区和反馈。
- 保留易辨认的标准光标；剪刀形态可作为画布内的工具提示，避免全站拖尾影响定位。
- 视觉主题可称“朱砂映纸／夜窗透光”，不称“阳刻／阴刻”。主题切换列为增强项。
- 纸张摩挲、裁剪和展开音效由用户主动开启，默认不自动播放音乐。
- 提供减少动画选项；重要状态同时使用文字或图形表达。

## 六、首版范围与扩展顺序

### 第一阶段：做通一个完整体验

交付内容：

- 作品名称、导航和首页导入统一。
- 一个出处明确的文化案例及对应转化演示。
- 一条“剪一份今天的祝福”任务和三段入门练习。
- 对称工坊与连接提示复用、任务上下文衔接。
- 窗格与祝福海报两种场景。
- 剪纸图、海报图、创作卡导出，以及可继续编辑的本地收藏。

完成标准：新用户能沿主线完成并导出一件作品；能从工坊回看参考案例；保存后能继续修改；预览与导出的图案一致；页面中所有文化案例均有出处或明确的原创说明。

### 第二阶段：补足地域内容与创作能力

- 扩展三组地域案例与约 6—8 张元素卡。
- 增加平面自由剪，并验证撤销、保存、预览和导出。
- 增加“把家乡剪进今天”任务。
- 加入阴阳刻对照教学与一类文创样机。
- 依据实际手机体验完善触控与下载流程。

### 第三阶段：增强表现力

- 优化首页层叠纸景、光影和可控音效。
- 在素材充分时加入家乡记忆专题及原创剪纸动画。
- 根据实际尺寸研究细连接提示和打印输出。
- 评估完整阴阳刻编辑模式。

不预设工期；先确认团队人数、素材准备情况与提交日期，再为每阶段安排时间。首页效果优先级低于主任务和导出流程。

## 七、素材清单与体验验证

### 素材准备

首版需要：一份可使用的文化案例图和资料说明、一组局部讲解标注、一套原创转化演示、一套分离连接练习图、一个可编辑剪纸模板、一个窗格场景、两款海报版式和一款创作卡版式。

所有文化资料记录来源；作品名称、地域称谓和具体寓意按来源核实。优先从非遗机构、博物馆、正式出版物或传承人公开资料采集。以下资料可用于一般背景和技法参考，不能替代具体山东案例的出处：

- [UNESCO：中国剪纸](https://ich.unesco.org/en/RL/chinese-paper-cut-00219)
- [中国非物质文化遗产网：剪纸艺术](https://www.ihchina.cn/news_1_details/11473.html)

### 体验验证

邀请约 5 名初学者试用，作为问题发现，不据此宣称普遍教学效果。记录：

- 是否理解首页任务并知道下一步入口。
- 是否能指出一个参考案例与自身作品的联系。
- 是否能解释局部剪口与对称图案的关系。
- 遇到连接提示后是否知道怎样处理。
- 是否能够独立保存、重新打开并导出作品。

检查范围包括桌面主要流程、目标手机触控、导出结果、音效开关及减少动画模式。根据真实卡点修改文案和交互，不以增加动画代替修复流程。

## 九、作品简介（新版策划口径）

《剪映古今》是一款以山东剪纸为文化基础的网页互动作品，面向青少年及剪纸初学者，围绕“认识传统、理解方法、自主创作、融入生活”构建体验流程。

作品拟从具有明确出处的地域剪纸案例出发，通过局部观察、纹样解读和分步设计演示，引导用户认识剪纸的造型与构图方法。在数字工坊中，用户可通过对称裁剪、实时预览和连接提示完成自己的作品，再将成果用于窗花展示、祝福海报等生活场景。

作品以“纸间寻根、纹样新生、指尖剪艺、一纸入生活”四个模块连接文化学习与个人表达，将宣纸肌理、剪纸镂空和窗格光影融入视觉设计，探索山东剪纸在数字媒介中的互动呈现与当代应用。
