# 纸上生花 · 非遗剪纸数字艺术空间

> 2026 年第十四届全国大学生数字媒体科技作品及创意竞赛 · 参赛作品

一个以中国非物质文化遗产「剪纸」为主题的单页交互式数字艺术空间。作品把剪纸文化放进一座可逛、可剪、可收藏的「纸上剧场」：既用 2.5D 立体纸雕与光影叙事讲清剪纸的美与文化，也提供一套真正能上手折剪的在线剪纸工坊，让观众从「看」走到「剪」。

**主文件：[`zhishang_shenghua_home.html`](zhishang_shenghua_home.html)** — 单文件自包含，双击即可在浏览器中打开体验。

---

## 一、作品定位

面向**剪纸初学者与大众观众**，用两条线并行推进：

- **文化线**：从花窗、母题、吉祥寓意切入，先让观众明白「为什么剪」——每一枚纹样背后的民俗语境与祝福含义。
- **技法线**：再让观众亲手「怎么剪」——选折法、落剪、展开、检视连接结构，完成属于自己的第一幅窗花。

设计上刻意避免把非遗做成静态图文陈列：所有文化内容都嵌入可操作、可反馈的交互场景中，让「看展」变成「动手」。

## 二、作品构成

作品由**首页长卷**与**四个核心模块**组成，通过顶部导航在单页内切换。

### 1. 首页长卷 —— 2.5D 立体纸雕叙事剧场

以「窗格透光」与「皮影戏台」为意象，把首页做成一座层叠的立体纸雕舞台。

**第一幕 · 双鱼戏莲立体纸雕**

- 舞台由 **6 层 Z 轴平面**（`z-plane-0` ~ `z-plane-5`）堆叠而成，从背景满月圆窗、水波纹涟漪，到前景飞溅水花与纸燕，逐层拉开景深，营造纸张悬空浮起的立体浮雕感。
- 核心是 **Canvas 实时弹性波浪引擎**驱动的「双鱼戏莲」剪纸母题，鱼身随水波连续弯曲摆动，而非静态贴图。
- 三种可切换母题：**双鱼戏莲 · 连年有余**、**凤穿牡丹 · 千刀团花**、**瑞鹿衔芝 · 万象更新**。
- 满窗纹样（mandala）支持 **六瓣 / 八瓣 / 十二瓣** 三种对称密度一键切换，配合多层同心环旋转动画。
- 「立体景深」滑杆可实时调节层间距，直观呈现 2.5D 分层结构。

**第二幕 · 六扇花窗门户**

取江南古典园林漏窗之形，以错落布局呈现花窗卡片，步移景异。当前实装五座轩馆：

| :--: | --- | --- | --- |
| 壹 | 满月圆窗 · 双燕裁云 | 剪纸工坊 | 指尖落刀 · 对称造物与千刀不断 |
| 贰 | 海棠花窗 · 宝相缠枝 | 纹样灵感 | 寻脉千载 · 传统民俗吉祥母题谱系 |

| 伍 | 蕉叶轩窗 · 宫灯流苏 | 灵犀文创造物 | 器以载道 · 窗花光影与东方生活美学 |

### 2. 剪纸工坊 —— 核心互动模块

把剪纸「折、剪、展」的仪式感还原到网页上。

- **折法**：四瓣 / 六瓣 / 八瓣三种对称份数。剪下一处，对称生成整幅图案。
- **剪法工具**：柳叶剪、圆孔剪、月牙角，以及逐点描绘自定义镂空的**自由剪**。
- **可调剪口尺寸**，配合折线辅助线预览对称结果。
- **撤销 / 重做**：`Ctrl+Z` 撤销、`Ctrl+Shift+Z` 重做。
- **展开动效**：点击「展开这份心意」，剪口从折叠形态生长为完整窗花，贴上古宅木棂花窗。
- **千刀不断 · 连接结构检测**：实时分析镂空后的连通区域，高亮可能脱落的独立区域与过细连接处——这是本作品区别于普通绘图工具的技术亮点，直接对应剪纸「千刀不断、万眼相连」的工艺核心。
- **收藏与导出**：作品可收藏进浏览器作品匣，或导出为 **1200 × 1200 透明 PNG** 与**矢量 SVG**（可缩放打印）。

### 3. AI 创意伙伴 —— 说出心意，生成剪纸草案

写下赠送对象与祝福主题（或点击「灵感速填」：毕业前程似锦 / 新春岁岁平安 / 佳偶繁花似锦 / 长辈福寿绵长），系统即时生成一份**可编辑的对称几何剪纸草案**，可一键载入画布继续裁剪、检查连接并展开。

> **实现说明（如实标注）**：该模块为**浏览器本地规则生成**——依据文案中的关键词（如「四瓣 / 六瓣 / 八瓣」「婚嫁 / 学金 / 青绿」）匹配折法、纸色与主题，再以固定种子程序化生成对称剪口几何，**不调用任何外部大模型接口，也不发送任何请求**。它给出的是可直接编辑的「几何草案」而非成图，定位是帮初学者跨过「第一笔怎么下」的门槛。生成过程可导出为 AI 创作记录 JSON。

### 4. 纹样灵感

非遗母题与原创练习谱系的画廊。纹样可一键载入工坊创作台二次雕琢，把经典母题变成亲手裁剪的变化。

### 5. 我的作品

收藏匣，读取浏览器本地存储（键名 `zhishang_shenghua_collection_v1`）。每件作品可贴窗赏析、继续创作或导出。无收藏时展示引导空状态。

## 三、操作说明

**通用**

- 顶部导航切换「首页长卷 / 剪纸工坊 / 纹样灵感 / 我的作品」。
- 四款浸染纸色主题一键切换：**丹霞流金 / 胭脂春晓 / 天青烟雨 / 琥珀泥金**。
- **琉璃夜窗**：切换昼夜光影模式，夜间呈现暖灯透窗的效果。
- **古琴五声泛音**：Web Audio 实时合成的音效开关。
- 「初次来访？」帮助对话框，三步引导首次创作。

**工坊**

| 操作 | 说明 |
| --- | --- |
| 点击纸面 | 以当前剪法剪出一枚对称剪口 |
| 自由剪 | 依次点击至少三个点描绘路径，`Enter` 或「完成路径并裁剪」成型，`Esc` 取消 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做 |
| 展开这份心意 | 播放展开动效并生成完整窗花 |

## 四、视觉与交互设计

- **配色**：以宣纸暖白、朱砂红、泥金为基调，摒弃纯白配纯红的刺眼搭配，构成新中式色系；每套浸染主题可整体改变纸色氛围。
- **纸张质感与光影**：全局叠加宣纸纤维噪点纹理；剪纸层使用多层 `drop-shadow`，配合随鼠标位移的光源，营造纸张悬空的立体浮雕感。
- **生长动效**：利用 SVG `stroke-dasharray` / `stroke-dashoffset`，让纹样在进入视口时如被无形刻刀实时刻出般生长呈现。
- **沉浸式细节**：垂直排版的诗句与朱砂印章点缀、随滚动铺展的雕刻藤蔓云纹、飞溅水花与纸燕粒子。
- **双模式**：由常见深浅色改造为剪纸本体的「琉璃夜窗」昼夜切换，视觉反差强烈且贴合主题。

## 六、运行方式

**主作品**：直接用浏览器打开 `zhishang_shenghua_home.html` 即可，无需安装、无需构建、无需本地服务器。

> ⚠️ 该文件通过 CDN 引入 **Tailwind CSS** 与 **Google Fonts（Inter、Noto Serif SC）**，因此**首次打开建议联网**；离线状态下字体与部分工具类样式会降级，核心交互与 Canvas 动画不受影响。作品中所有剪纸图形与逻辑均内嵌于文件内（含内嵌 base64 原图），不会上传或外发任何数据。

**初版原型**：用浏览器打开 `papercut-web/dist/index.html`，同样无需依赖与构建。

## 七、技术实现

| 项目 | 说明 |
| --- | --- |
| 技术栈 | 原生 HTML / CSS / JavaScript，无框架、无构建步骤 |
| 样式方案 | Tailwind CSS（CDN） + 内联自定义 CSS 变量主题系统 |
| 图形渲染 | Canvas 2D 实时动画引擎（双鱼波浪、水花粒子、满窗纹样）+ SVG 路径生长动画 |
| 立体效果 | CSS 3D `perspective` / `translateZ` 多层 Z 平面 + 动态 `drop-shadow` 光影 |
| 音频 | Web Audio API 实时合成古琴五声泛音，无音频文件依赖 |
| 数据持久化 | 浏览器 `localStorage`（收藏匣 `zhishang_shenghua_collection_v1`） |
| 导出 | Canvas 导出 1200 × 1200 透明 PNG；程序化生成矢量 SVG |
| 连接检测 | 栅格化连通区域分析，过滤微小碎片并将最大连通域视为主体 |
| 无障碍 | 语义化标签、`aria-label` / `aria-live`、键盘操作、减少动画偏好支持 |

主文件为单文件结构：配置数据（浸染配色、三种母题、五座花窗门户）集中定义于内联脚本顶部，便于按同一份数据模板扩展新模块；页面样式、脚本与图形资源全部内联，因此可脱离服务器直接分发。

## 八、已知边界

- 本作为**二维对称剪纸**原型，展开为展示动效，不含任意折叠的物理模拟。
- 连接检测基于栅格与四邻域近似，**极细连接、抗锯齿边缘与微小碎片可能判断不准**；暂未实现纸张强度与过细连接分析。
- 「AI 创意伙伴」为本地规则生成的可编辑几何草案，非图像生成模型。
- 作品仅保存在当前浏览器，清理浏览器数据或更换访问地址可能丢失，重要作品请导出留存。
- 导出 SVG 可缩放打印，但**尚未指定实体打印尺寸**。
- 「九州流派长卷」「灵犀文创造物」为预留拓展位，尚未实装内容。

本项目在推进过程中形成过若干方案，部分已落地、部分留作后续方向，记录如下：

**已实现**

- ✅ 2.5D 视差纸雕剧场（方案 A 的核心创意）——六层 Z 平面 + 光源随动 + 滚动叙事。
- ✅ 虚拟折纸与实时镂空工坊（方案 B 的核心创意）——折、剪、展完整链路，含连接检测。
- ✅ 「阳刻 / 阴刻」式双模式——以「琉璃夜窗」昼夜模式落地。
- ✅ 纸张肌理与光影层次、裁剪微交互与纹样生长动效、沉浸式音效反馈。
- ✅ 无外部依赖的本地运行，用实际试用验证操作可学可用。

**后续方向**

- ⭕ 历史沿革与各地流派图谱（沂蒙 / 高密 / 胶东渔家 / 陕北 / 蔚县 / 扬州 / 佛山剪纸等）。
- ⭕ 现代化模块：冬奥、航天、经典动画与革命老区主题纹样。

- ⭕ 非对称、不对折的剪纸创作模式。
- ⭕ 精修校验：更严谨的纸张强度与连接分析、实体打印尺寸规范。
