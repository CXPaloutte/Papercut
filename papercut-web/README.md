直接打开 `dist/index.html` 查看首页，无需安装或构建。所有页面资源、字体与逻辑均在本地；网页不会自动请求外部服务。已有剪纸工坊在 `dist/workshop.html`。

## 首页重设计

### 四幕完整纸景

- 双鱼使用原图完整选区，撤销旧版切尾旋转与重叠拼接，改用连续弯曲保留腹部、鱼鳍、鱼尾和镂空。鱼处于浪层前方，静止与跃起时均可检视完整尾部。头部引导小幅转动、整体沿弧线抬升、尾部延迟轻摆，最后缓冲回落。
- 荷花按原作剪纸语言重绘连续花茎、花托与七片相连花瓣。花茎沿轮廓长出，花苞跟随真实茎顶，随后花瓣围绕共同根部舒展；删除旧版照片扇形分块。单独重播完整生长约 3.9 秒，开场生长约 3.1 秒；跳过开场同步呈现盛开状态。
- 龙、穆桂英、长卷使用整幕宣纸空间，移除作品卡片和框板。文字位于留白，云纹越过场景边缘，手机另排竖向画面。手机较长场景允许自然上下滚动，不缩小文字强行塞入一屏。
- 腾龙按《龙飞大有年》的红绿配色、月牙鳞纹与细纹语言重新绘制整条矢量盘龙。龙首、连续龙身、四肢、须、尾使用统一绘制方式；不再拼接照片龙首。龙首先行，沿连续中心曲线向尾部传递动作，所有鳞纹、背鳍和肢体跟随同一曲线。
- 穆桂英保留参考截图中的人物选区与面部。四面新增三角靠旗固定于背后腰位，人物在旗前；旗杆围绕固定根点小幅抬升，旗面靠杆边不动，自由边缘轻弯、旗尾滞后。各旗依次启动、抬升、停顿、微落，支持重播、眨眼与幅度调整。原截图本身上下不完整，选区按现有清晰度展示，不冒称完整原作复原。
- 长卷保留原比例、去除底板，随滚动逐步铺展，亦可重播或手动控制展开量。纹样和试剪图形保留点击反馈。
- 固定“暂停动画”统一冻结动作；减少动画偏好直接显示舒展构图。屏外或页面转入后台暂停闲置动画。导航、查看原作、工坊、收藏及导出继续可用。

场景实现为 `dist/world.css`、`dist/world.js`，基础导航、开场与原作查看器在 `dist/ocean.css`、`dist/ocean.js`。旧 `living-paper` 文件保留但首页不再加载。

项目原图独立保存在 `dist/assets/works/`，可从各幕入口查看、缩放、拖动。画面标明再设计与数字补绘，作者、地域和授权未知项不推定。素材与结构参考记录在 `dist/SOURCES.md`；未新增下载网络作品图片。

## 文件与复现

首页结构：`dist/index.html`；当前样式与动作：`dist/ocean.css/js`、`dist/world.css/js`；分层：`dist/assets/scene/`；原作：`dist/assets/works/`。

`prepare-scene.py` 提取原始鱼、花卉与纹饰，`prepare-animations.py` 提取人物、眼部和原作水纹；`prepare-restoration.py` 从完整鱼选区生成连续弯曲版本，同时绘制完整矢量龙。`restoration.json` 记录当前鱼修复。前两份脚本保留的旧切尾和龙首分层输出不再用于首页。`dragon-complete.svg` 与 `dragon-rig.json` 是完整龙的独立输出，首页内联同一图形与曲线数据。原始文件不被覆盖。页面使用原生 JavaScript 函数组织。

本轮为现有本地项目修改，没有新建或发布线上站点。旧首页和说明备份在 `qa-output/before-fish-ocean.html`、`qa-output/before-fish-ocean-README.md`；旧版 theater 文件保留但首页不再加载。

## 使用方法

在纸面点击即可剪切，所有操作会按当前折法镜像重复。自由剪依次点击至少三个点，按 Enter 或「完成路径并裁剪」结束；Esc 取消。Ctrl+Z 撤销，Ctrl+Shift+Z 重做。

## 首版边界

这是一款二维对称剪纸原型。展开为展示动画，不包含任意折叠的物理模拟。连接检测使用 360 × 360 栅格和四邻域，过滤小于 6 像素的区域，将最大连通区域视为主体；非常细的连接、抗锯齿边缘及微小碎片可能判断不准。暂未实现纸张强度和过细连接分析。几何模板为原创练习，不作为有考证的传统谱样。

作品仅保存在当前浏览器，同一文件位置或同一网站地址下可恢复；清理浏览器数据或更换地址可能丢失，重要作品请导出。PNG 为 1800 × 1800 透明图片，SVG 可缩放打印，但尚未指定实体打印尺寸。

代码采用原生 JavaScript 函数组织，无构建步骤。核心几何逻辑在 `dist/geometry.js`，界面与状态管理在 `dist/app.js`。
